# Data Science & Analytics Internship Tasks 📊🚀

## 📌 Overview
This repository contains my completed work for the **DevelopersHub Corporation – Data Science & Analytics Internship Program**.

The internship tasks are designed to build strong foundational skills in:
- Data exploration and visualization
- Data preprocessing and cleaning
- Machine learning model building
- Performance evaluation using metrics
- Extracting insights from data

Each task has been completed using **Python**, and includes a well-documented Jupyter Notebook with visualizations, model training, evaluation, and conclusions.

The main objective of this internship is to gain hands-on experience in real-world data science workflows including:

- Working with real datasets

- Building classification and regression models

- Understanding feature relationships and importance

## 📂 Tasks Completed

### ✅ Task 1: Iris Dataset Exploration & Visualization 🌸
**Objective:** Perform dataset inspection and create visualizations using Iris dataset.  
**Key Work:**
- Dataset loading and inspection
- Scatter Plot, Histogram, Box Plot
- Basic EDA insights


---

### ✅ Task 2: Credit Risk Prediction (Loan Prediction) 💳
**Objective:** Predict whether a loan applicant is likely to be approved or rejected.  
**Key Work:**
- Handling missing values
- EDA visualizations (loan amount, income, education)
- Logistic Regression model training
- Accuracy + Confusion Matrix evaluation


---

### ✅ Task 3: Customer Churn Prediction (Bank Customers) 🏦
**Objective:** Predict which customers are likely to leave the bank.  
**Key Work:**
- Data cleaning and preparation
- Encoding categorical variables (Geography, Gender)
- Classification modeling
- Feature importance analysis


---

### ✅ Task 4: Predicting Insurance Claim Amounts 🏥
**Objective:** Predict insurance charges using regression modeling.  
**Key Work:**
- Data exploration and visualization
- Linear Regression model training
- Model evaluation using MAE and RMSE
- Analysis of BMI, age, and smoking impact


---

### ✅ Task 5: Personal Loan Acceptance Prediction 📈
**Objective:** Predict which customers are likely to accept a personal loan offer.  
**Key Work:**
- Feature exploration (age, job, marital status)
- Logistic Regression / Decision Tree classification
- Accuracy + Confusion Matrix evaluation
- Business insights extraction
